This archive is the evidence package for one signed determination made in Lexvay, assembled so that a reviewer outside the institution can see what was decided and what it rests on.
It holds the evidence report, the exact rule version and course versions the determination is locked to, every quoted passage with the source document it was taken from, and the audit entries about the determination.
To check it, compute the SHA-256 hash of each file and compare it with the hash listed for that file in manifest.json; the manifest also gives each file's size and the time the package was generated.
Findings in this package were proposed by software and verified against the stored document text, and the determination itself was made and signed by the person named in determination.json.
