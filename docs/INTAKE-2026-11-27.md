## Runtime and cost facts
- The LLM provider defaults to `fake`. `AnthropicLlmClient` exists and is metered.
- No paid provider is called in tests or CI, and nothing is configured to call one at runtime. There is no explicit
  spend gate; the default is the only guard.
- No local-inference adapter exists.
- Demo versus real is not a persisted mode. The fictional banner is driven by a configured list of tenant names
  (`lexvay.demo-tenant-names`, D-064). No rule prevents a real tenant from using the scripted fake model or the seed.
- No paid service, subscription or trial has been bought. No university system or real customer data has been
  accessed. No crawler has run against a real source.

  `BLOCKED: expert review`.
- No pilot institution and no authorized academic source exists.
- No local inference hardware or model has been benchmarked.
- The rights to store university handbook text in this repository have not been reviewed. Until they are, university
  content is never committed; runtime copies stay in the local file store.
