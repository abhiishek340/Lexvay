### Spec points
1. **Rules: version list and detail with hairlines** (D-520 to D-523): two columns under a hairline, a vertical hairline
   between; the versions as a text list whose selection is accent-wash with the 2 px accent rule; each status a
   StatusMark and its word (five shapes, tested; Approved a disc in `ink`, never `found`); the version's label in Title type, its facts as one meta line, its
   state as one mark and sentence; the requirement list as a four-column table aligned on the first baseline, with the
   rule text in Document type; the edit grid on the 4 px grid, its icon buttons square, its terms drawn as Labels; the
   approval dialog a Figure and one paragraph; the new-version dialog with the rule text in Document type and no mono.
2. **The diff in Document type with `found` and `missing` underlines** (D-525): inserted text underlined in `found`,
   deleted text struck through in `missing` (DiffText, plus a quarter-em gap between a deletion and its replacement);
   no tinted blocks, no summary pills, no arrow icons; added and removed requirements wholly inserted or deleted; the
   changes first, the unchanged requirements behind "Show 8 unchanged".
3. **Search-term chips are Labels** (D-524), read-only, while editing and in Compare.
4. **Evidence requests: a table, with the answer drawer as an overlay sheet** (D-526, D-529): the filter an underlined
   text row with counts, statuses as marks and words, the row action an accent text action; the shared Sheet floats
   12 px inside the window with the overlay radius and elevation and fades in over 150 ms; inside it the requirement
   is set on a rule, without the sunken inset, card and avatars.
5. **Program setup: the numbered text step list on the left and plain forms on the right** (D-527): no discs, no check
   icons; Details a definition list, States, Courses and Documents tables (Documents grouped by course in place of the
   card grid), Program facts rows between hairlines.
6. **Readiness with its own neutral check and cross** (D-528), whether a line blocks in words, fixes as text actions,
   the run as one plain row with the Meter.
